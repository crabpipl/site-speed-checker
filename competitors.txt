# ─────────────────────────────────────────────────────────────
#  СТРАНИЦЫ КОНКУРЕНТОВ ДЛЯ СРАВНЕНИЯ (необязательный файл)
# ─────────────────────────────────────────────────────────────
#  Работает, только если в settings.txt включено:
#    сравнение с конкурентами = да
#  (или при запуске с флагом --competitors).
#
#  Одна строка — одна группа похожих страниц:
#    Название = наша страница ; страница конкурента ; страница конкурента
#
#  Наша страница должна быть в pages.txt — её замер берётся из той же
#  проверки. Страницы конкурентов замеряются в тех же условиях, но без
#  углублённых тестов. Сравнивайте похожие страницы: главную с главной,
#  каталог с каталогом, карточку товара с карточкой похожего товара.
#
#  Пример (уберите # в начале строк, чтобы включить):
#
#  Главная  = https://store.example.com/ ; https://competitor-a.example.com/ ; https://competitor-c.example.com/
#  Смартфоны = https://store.example.com/smartfony/ ; https://competitor-a.example.com/catalog/smartfony/
