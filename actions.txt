# ─────────────────────────────────────────────────────────────
#  Если для сайта ничего не задано, агент сам определяет тип страницы
#  и нажимает стандартный набор элементов:
#   • каталог  — «Фильтры», «Сортировка», «Показать ещё», меню, поиск;
#   • карточка — выбор размера/варианта, «В корзину», галерея, меню, поиск;
#   • другие   — меню, галерея, поиск.
#
#  Здесь можно задать для сайта ТОЧНЫЙ список нажатий. Секция начинается
#  с имени сайта в квадратных скобках (без www и https://), дальше строки:
#
#   каталог  = что нажимать на страницах каталога
#   карточка = что нажимать на карточках товаров
#   другие   = что нажимать на остальных страницах
#   поиск    = слово для проверки поиска  (поиск = нет — не проверять поиск)
#   адреса каталога  = часть адреса, по которой страница — каталог  (если агент путает тип)
#   адреса карточки  = часть адреса, по которой страница — карточка товара
#
#  Действия перечисляются через «;». Каждое — это видимый текст кнопки
#  (как на сайте, регистр не важен) или CSS-селектор с приставкой «css:».
#  Если для типа страницы задан список, нажимается ровно он, по порядку.
#  Если элемент не найден на странице, это будет видно в отчёте.
#
#  Пример (уберите # в начале строк, чтобы включить):
#
#  [shop.example.com]
#  каталог  = Фильтры; Сортировка; Показать ещё
#  карточка = css: .product-sizes button; В корзину
#  поиск    = кроссовки
#  адреса каталога = /cat/
#  адреса карточки = /d/
