# ─────────────────────────────────────────────────────────────
#  ТЕСТ ОФОРМЛЕНИЯ ЗАКАЗА — настройки (npm run audit:checkout)
# ─────────────────────────────────────────────────────────────
#  ВНИМАНИЕ: тест оформляет НАСТОЯЩИЙ заказ. После теста отмените его.
#  Чтобы проверить сценарий без заказа: npm run audit:checkout -- --no-order
#
#  Код агент спрашивает в Терминале при каждом запуске. Телефон или почту
#  можно указать здесь (строки «телефон» и «почта»), тогда агент не будет
#  их спрашивать. Этот файл личный и в репозиторий не попадает.
#
#  Секция начинается с имени сайта в квадратных скобках (без https://).
#  Для тестового стенда — отдельная секция с его доменом.
#
#  Кнопки и варианты пишутся ТЕКСТОМ, как на сайте (регистр не важен,
#  хватит начала надписи; цену и дату не пишите),
#  или CSS-селектором с приставкой «css:». Несколько вариантов — через «;»,
#  нажимается первый, который есть на странице.
#
#  НОВЫЙ САЙТ: достаточно строки «товар = …» и проверки сценария
#   npm run audit:checkout -- --check --site=shop.example.com
#  Агент сам закроет окна выбора региона, cookies и промо, найдёт иконки
#  входа и корзины, адрес корзины, а там, где не справится, покажет в
#  Терминале и в отчёте похожие кнопки с готовыми строками для этого файла.
#  Размер или цвет агент выбирает сам (первый доступный) — или укажите его в «вариант».
#
#  ИЛИ ЗАПИСЬ: пройдите оформление сами в открытом браузере — агент запомнит
#  нажатые кнопки и сам впишет секцию сайта в этот файл (заказ не создаётся):
#   npm run audit:checkout -- --record --site=shop.example.com
#
#  Обязательные строки:
#   товар      = адрес карточки товара (недорогого, который точно есть в наличии);
#                несколько товаров — через «;» или несколькими строками «товар = …»
#   получение  = текст способа получения, например: Самовывоз; В магазине
#   оплата     = текст способа оплаты, например: При получении
#                (для проверки --check их можно не указывать — агент подскажет варианты)
#
#  Необязательные (если не указать — агент попробует типовые тексты и сам найдёт
#  иконки входа и корзины; указанные здесь варианты пробуются первыми):
#   разрешение      = мобильный | десктоп            (по умолчанию мобильный)
#   вход            = телефон | почта | спрашивать   (по умолчанию спрашивать)
#   телефон         = 10 цифр без кода страны, например 9001234567
#   почта           = адрес для входа по почте, например name@example.com
#   адрес корзины   = адрес страницы корзины (если не указан — ищется по ссылкам на сайте)
#   вариант         = авто | нет | значения через «;» — размер, цвет, объём товара
#                     (авто — по умолчанию: уже выбранный или первый доступный;
#                     например «вариант = 42» или «вариант = M; Чёрный»)
#   удалять другие товары = да | нет  (по умолчанию да: товары, которые уже
#                     лежали в корзине аккаунта, удаляются, в заказ попадают
#                     только товары из этого файла; «нет» — тест остановится,
#                     если корзина не пуста)
#   обновлять карточку = да | нет (по умолчанию да: карточка товара открывается,
#                     затем обновляется, и товар кладётся в корзину уже с
#                     прогретым кэшем — как у вернувшегося покупателя)
#   удалить товар, меню товара, подтвердить удаление — кнопки удаления
#                     товара из корзины, если на сайте они другие
#   пустая корзина  = текст, который сайт пишет в пустой корзине
#   показать магазины   = кнопка, которая переключает карту магазинов на список
#   магазин         = название магазина или пункта выдачи, как в списке на сайте
#   подтвердить магазин = кнопка рядом с магазином, например: Забрать здесь
#   закрывать       = кнопки плашек, которые мешают нажимать, если агент не закрыл
#                     их сам (окна региона, cookies и промо он закрывает сам)
#   перед оформлением   = дополнительные нажатия перед заказом (через «;»)
#   оформить        = кнопка заказа (по умолчанию «Оформить заказ»)
#   открыть вход, вход по телефону, вход по почте, получить код,
#   поле кода, подтвердить код, код повторно, в корзину, перейти в корзину,
#   к оформлению, признак заказа, выход, адрес профиля — если тексты на
#   сайте отличаются от типовых
#
#  Проверить сценарий без входа и без заказа: npm run audit:checkout -- --check
#
#  Если выбрана онлайн-оплата картой, агент дойдёт до формы банка, замерит
#  её загрузку и остановится — данные карты он не вводит.
#
#  ОБЩИЕ НАСТРОЙКИ И ШАБЛОНЫ:
#   [все сайты]           — секция, строки которой действуют на все сайты
#                           (удобно для «телефон», «разрешение», «вход»)
#   основа = другой сайт  — в секции сайта: взять все настройки другого сайта
#                           из этого файла и указать здесь только отличия
#                           (для сайтов одной платформы с похожими кнопками).
#   Порядок: [все сайты] → основа → строки самого сайта (последние важнее).
#   Адреса (товар, адрес корзины, адрес профиля) у каждого сайта свои
#   и не берутся из основы.
#
#   [все сайты]
#   разрешение = мобильный
#   телефон    = 9001234567
#
#   [store.example.com]
#   основа  = shop.example.com
#   товар   = https://store.example.com/d/item/
#   магазин = ул. Другая, 5
#
#  КУРЬЕР ИЛИ САМОВЫВОЗ: один тест — один способ получения.
#  Есть строка «адрес доставки» — заказ оформляется курьером,
#  нет — самовывозом (магазин из строки «магазин»). Чтобы сменить
#  способ, поправьте строки в секции сайта.
#   адрес доставки  = город, улица, дом — агент вводит адрес как человек
#                     и выбирает подходящую подсказку сайта
#   квартира, подъезд, этаж, домофон, комментарий курьеру — по желанию
#   получатель      = имя получателя (если сайт не подставил его сам)
#   телефон получателя = по умолчанию — телефон для входа
#   дата доставки   = первая доступная (по умолчанию) или текст:
#                     «завтра», «23 октября», «пт»
#   интервал        = первый доступный (по умолчанию) или «10:00 - 18:00»
#   подтвердить адрес = кнопка, если адрес вводится в отдельном окне
#                     (по умолчанию агент ищет «Сохранить», «Готово» и т. п.)
#
#   Курьер — в секции сайта вместо строк «магазин»:
#   получение      = Курьерская доставка
#   адрес доставки = Москва, ул. Примерная, 1
#   квартира       = 1
#
#  Пример (уберите # в начале строк, чтобы включить):
#
#  [shop.example.com]
#  товар          = https://shop.example.com/catalog/cable-usb-c/; https://shop.example.com/catalog/charger/
#  разрешение     = мобильный
#  вход           = телефон
#  адрес корзины  = https://shop.example.com/cart/
#  получение      = Самовывоз
#  показать магазины = Показать списком
#  магазин        = ул. Примерная, 1
#  подтвердить магазин = Забрать здесь
#  оплата         = При получении
# ─────────────────────────────────────────────────────────────
