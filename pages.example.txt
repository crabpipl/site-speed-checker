#  Правила:
#   • одна строка = один полный адрес страницы, начиная с https://
#   • адреса можно добавлять просто списком — заголовки не нужны
#   • страницы разных сайтов можно смешивать в любом порядке:
#     агент сам определит сайт по адресу и сложит отчёты
#     в reports/<сайт>/<дата_время>/ (www. в имени папки отбрасывается)
#   • удалить страницу — удалите строку
#   • временно не проверять — поставьте # в начале строки
#   • строки с # — комментарии, на проверку не влияют;
#     их можно использовать как подписи для себя (# Каталог, # site.ru)
#   • пустые строки пропускаются, повторы проверяются один раз
#
#  Проверить, какие страницы попадут в замер и в какие папки:
#   npm run pages
