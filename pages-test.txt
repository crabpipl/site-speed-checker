#  СТРАНИЦЫ ТЕСТОВОГО КОНТУРА (запуск: npm run audit:test)
# ─────────────────────────────────────────────────────────────
#  Секция в квадратных скобках — тестовый домен и прод-домен:
#    [тестовый домен = прод-домен]
#  Под ней — адреса тестовых страниц. Для каждой агент замерит тот же
#  путь на проде и покажет в отчёте «Тест против прода».
#  Без секции страница проверяется без сравнения с продом.
#
#  Пример (уберите # в начале строк, чтобы включить):
#
#  [store.stage.company.local = store.example.com]
#  https://store.stage.company.local/
#  https://store.stage.company.local/smartfony/
